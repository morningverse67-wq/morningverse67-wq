# CarryOn

**Your AI coding session is 92% full. Back it up, compact it, carry on.**

A free macOS menu-bar app for people who run many Claude Code, Codex and Aside sessions.

**[⬇ Download for macOS](https://github.com/morningverse67-wq/carryon-app/releases/latest)** &nbsp;·&nbsp; [Website](https://carryon-app.pages.dev) &nbsp;·&nbsp; macOS 14+ · Free

<a href="https://carryon-app.pages.dev"><img src="https://raw.githubusercontent.com/morningverse67-wq/carryon-app/main/docs/img/demo.gif" width="560" alt="CarryOn backing up a session at 92% context, compacting it, and showing 18%" /></a>

</div>

- **See every session's context** — what's waiting for you, what's almost full, what's running.
- **Back up & compact in place** — Claude Code and Codex keep going in the same session.
- **Clean up idle sessions** — and see which ones read the most tokens in the last 24 hours.

```sh
curl -fsSL https://carryon-app.pages.dev/install.sh | sh
```
