# CarryOn

**Every AI coding session, at a glance. Back up and compact the full ones with one press.**

For people who run many Claude Code, Codex, Aside and Gemini CLI sessions. **Free on Mac, Windows, iPhone and Android.**

**[⬇ Mac](https://carryon-app.pages.dev/download?s=github)** &nbsp;·&nbsp; **[iPhone (App Store)](https://apps.apple.com/app/id6831468074?ct=github)** &nbsp;·&nbsp; [Windows (Microsoft Store, beta)](https://carryon-app.pages.dev/download/windows?s=github) &nbsp;·&nbsp; [Android (beta testers wanted)](https://carryon-app.pages.dev/?s=github&lang=en#android) &nbsp;·&nbsp; [Website](https://carryon-app.pages.dev/?s=github&lang=en)

<sub>macOS 14+ · iOS 15+ · Windows 10 1903+ x64 · Android 7+ (the phone apps need CarryOn on your computer) · Free</sub>

<a href="https://carryon-app.pages.dev/?s=github&lang=en"><img src="https://raw.githubusercontent.com/morningverse67-wq/carryon-app/main/docs/img/demo.gif" width="560" alt="CarryOn backing up a session and compacting it (sample data)" /></a>

</div>

- **See every session's context** — what's waiting for you, what's almost full, what's running.
- **One press backs up and compacts** — CarryOn types `/compact` into the terminal of a running Claude Code session, right where it runs. The session stays open and keeps its memory.
- **Memory Guard** — when Claude Code compacts by itself, the conversation from just before is kept for 14 days, and your role, open to-dos and “Keep in mind” notes are put back right after.
- **One tap on the phone** — [Compact] in the phone's alert has your computer compact that session right away (Android now, iPhone from 1.8.0).
- **Roles and teams** — give a session a role, name a group of sessions as a team.
- **Close idle Claude Code sessions** — and see which ones read the most tokens in the last 24 hours.

```sh
curl -fsSL https://carryon-app.pages.dev/install.sh | sh
```
