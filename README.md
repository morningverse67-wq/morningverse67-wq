# CarryOn

**Your AI coding session is 92% full. Back it up, compact it, carry on.**

For people who run many Claude Code, Codex, Aside and Gemini CLI sessions. Free on the Mac. **New: Windows and Android betas are out.**

**[⬇ macOS](https://carryon-app.pages.dev/download)** &nbsp;·&nbsp; **[⬇ Windows (beta)](https://carryon-app.pages.dev/download/windows)** &nbsp;·&nbsp; **[⬇ Android (beta)](https://carryon-app.pages.dev/download/android)** &nbsp;·&nbsp; [Website](https://carryon-app.pages.dev/?lang=en)

<sub>macOS 14+ · Windows 10 1903+ x64 · Android 7+ (the phone app needs CarryOn on your computer) · Free</sub>

<a href="https://carryon-app.pages.dev/?lang=en"><img src="https://raw.githubusercontent.com/morningverse67-wq/carryon-app/main/docs/img/demo.gif" width="560" alt="CarryOn backing up a session at 92% context, compacting it, and showing 18%" /></a>

</div>

- **See every session's context** — what's waiting for you, what's almost full, what's running.
- **Back up & compact in place** — Claude Code and Codex keep going in the same session.
- **Start fresh in Orca** — on a Claude Code running in an Orca pane, one button backs it up, types `/clear` and the go-on message. Only when you press it, only while it's idle.
- **Roles and teams** — give a session a role, name a group of sessions as a team.
- **Close idle Claude Code sessions** — and see which ones read the most tokens in the last 24 hours.

```sh
curl -fsSL https://carryon-app.pages.dev/install.sh | sh
```
